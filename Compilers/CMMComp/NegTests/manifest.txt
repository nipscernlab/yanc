# Negative test manifest for regress.sh's CMM negative phase.
# Each fixture is a malformed .cmm that cmmcomp MUST reject with a clean
# non-zero exit (never a crash, never a silent accept) and the listed
# diagnostic substring (matched against -en output).
#
# format:  <fixture.cmm>|<expected substring>
# (lines starting with '#' and blank lines are ignored)
#
# These live in NegTests/ — a sibling of Tests/ — on purpose: the CI smoke
# test does `find Compilers/CMMComp/Tests -name '*.cmm'` and compiles every
# hit, so a deliberately-broken .cmm under Tests/ would fail CI.
syntax.cmm|Syntax error
no_main.cmm|main() function
garbage.cmm|Syntax error
undeclared.cmm|declared the variable
define_recursive.cmm|declare the variable
nugain_not_pow2.cmm|power of two
const_idx_scalar_read.cmm|ain't an array
const_idx_2d_read.cmm|has two dimensions
const_idx_scalar_write.cmm|isn't an array
const_idx_2d_write.cmm|has two dimensions
recursion.cmm|calls itself (fact -> fact)
cade_comp.cmm|cade() brings one word
names_mnemonic.cmm|'ADD' is an instruction of the processor
names_mnemonic_local.cmm|is 'S_ADD' in the assembly, which is an instruction
names_global_local.cmm|the local 'x' of 'main()' is 'main_x' in the assembly, and that name is already the global 'main_x'
names_local_local.cmm|is 'a_b_c' in the assembly, and that name is already the local 'c' of 'a_b()'
names_fun_global.cmm|the function 'f()' is 'f' in the assembly, and that name is already the global 'f'
names_comp_imag.cmm|is 'z_i' in the assembly, and that name is already the global 'z_i'
names_underscore.cmm|names starting with '__' belong to the compiler
names_fim.cmm|a function can't be called 'fim'
